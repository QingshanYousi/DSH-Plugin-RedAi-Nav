时长分层

四档时长覆盖全部场景。任何新动效都必须落进其中一档，不允许自创时长——这是"看起来像同一个产品"的最低成本手段。

反馈 80–120mshover / 按下 / 光标移动cubic-bezier(.25,1,.5,1)
状态 120–200ms收藏 / 选中 / 计数 / 描边cubic-bezier(.16,1,.3,1)
层级 180–260ms重排 / 详情进出 / 菜单cubic-bezier(.16,1,.3,1)
入场 260–320ms首屏分组 stagger 30mscubic-bezier(.16,1,.3,1)

六个方案

"与 DSH 一致"不是指长得像，而是三点：只用 --dsw-alias-* 语义 token 取色、时长落在 120–260ms、位移不超过 4–8px 且不用弹簧。凡是需要"表演"的方案都已排除。

#方案触发参数为什么符合 DSH降级
1星尘收藏点 ☆ / 取消 scale .86→1.14→1 240ms；4 颗尘埃 380ms 金色是全站唯一暖色，天然记忆锚点；取消收藏不喷尘——破坏性动作不该有奖励感 仅 80ms 变色
2键盘光标↑ ↓ / Tab 进入 左侧 2px 竖条 120ms；底 brand 8%；位移 1px 竖条就是 DSH 侧栏选中态的语言，复用同一符号＝同一家族 仅底色
3数字滚动搜索 / 切 tab translateY 对滚 140ms；等宽数字、行高不变 让"89→12"的因果被看见；不产生布局位移，属信息动效 直接替换
4域名浮出hover / 键盘选中 描述↔域名交叉淡入 130ms，行高 15px 不变 一行两条信息、高度零增长，密度不变的前提下解决同名站点歧义 直接替换
5交接确认点卡片打开 右移 4px 回位 160ms + 0.5px 品牌内描边 右侧栏在另一个视觉焦点区，"什么也没发生"是真实焦虑；4px 是方向隐喻不是特效 仅描边淡入
6筛选重排插件榜权限面筛选 FLIP 180ms；进出场 120ms + scale .985 12 条同时重排若瞬移，用户会丢失"刚看的那条"；只动 transform 不触发布局 无动画重排

明确不做的五件事

写下"不做什么"比写下"做什么"更能定义风格。以下五项都能让 demo 更抓眼，但会让每天用 20 次的人厌烦。

卡片 3D 倾斜 / 视差与 DSH 扁平、静态的表面语言冲突；密集网格里会晃眼。
骨架屏 / 假加载数据全在内存，制造假延迟是欺骗，也会让"快"变成"装快"。
弹簧 / 回弹缓动玩具感。开发者对 Q 弹极其敏感，一次就够毁掉专业感。
收藏时彩带庆祝收藏是日常动作，不是成就解锁；高频奖励=骚扰。
打字机 / 呼吸光效持续动效在阅读区等于噪声，还会抢走主会话的注意力。

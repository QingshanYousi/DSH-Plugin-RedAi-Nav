## 2. 拆分方案（4 模块 + 生成数据 + 拼装脚本）

### 2.1 目录

```
src/
  store.js        # helpers + store：纯函数，无 JSX，无 React
  components.js   # 站点卡片 / Banner / 站点详情 / 站点相关 CSS / 动效 CSS
  plugins.js      # 插件榜卡片 / 插件详情 / 排名函数 / 插件相关 CSS
  page.js         # NavPage + 导航行图标 + inject/apply + exports（唯一的 React 依赖面）
  data.js         # GENERATED by scripts/embed-data.mjs（勿手改）
scripts/build.mjs # 把 src/*.js 拼装成 lib/client.js（零依赖）
```

### 2.2 拼装契约（关键，必须逐字遵守）

四个模块是**同一个闭包内的四个片段**，不是 ESM。它们共享同一作用域，因此：

- 禁止出现 `import` / `export` 语句；模块间调用直接引用变量名。
- 声明顺序即依赖顺序：`data.js → store.js → components.js → plugins.js → page.js`。
- 所有 JSX 仍用 `jsx` / `jsxs`（来自 `require('react/jsx-runtime')`），`React` 仅在 `page.js` 用到 hooks。
- `store.js` / `components.js` / `plugins.js` 顶部不要 `const React = ...`；需要 hooks 时在 `page.js` 里已有。

`scripts/build.mjs` 生成的文件骨架（与现在字节兼容，便于 smoke 测试的 `new Function` 执行）：

```js
window.__ModuleLoader__.load({
  id: 'dsh-plugin-redai-nav',
  factory: (require) => {
    var module = { exports: {} }
    var exports = module.exports
    Object.defineProperty(exports, Symbol.toStringTag, { value: 'Module' })

    const React = require('react')
    const jsxRuntime = require('react/jsx-runtime')
    const jsx = jsxRuntime.jsx
    const jsxs = jsxRuntime.jsxs

    // ---- src/data.js ----
    // ---- src/store.js ----
    // ---- src/components.js ----
    // ---- src/plugins.js ----
    // ---- src/page.js ----
    return module.exports
  },
})
```

拼装要求：
- 每个片段缩进 4 空格写入，片段间空一行，注释标注来源 `// ── src/store.js ──`。
- **不压缩、不混淆**，产物必须逐行可读（这是本包的信任基础）。
- 产物首尾与现在一致；`id` 必须等于 `package.json` 的 `name`。
- `lib/client.js` 顶部保留 20 行以内的文件头注释，说明「由 src/*.js 拼装，勿直接编辑」。

### 2.3 CSS 归属

现在所有 CSS 在一个 `css` 数组里。拆分后：

- `components.js` 导出 `const cssSites = [...]`（站点卡片 / Banner / 详情 / 动效通用）
- `plugins.js` 导出 `const cssPlugins = [...]`（插件榜 / 插件详情）
- `page.js` 里组装并注入（唯一注入点，保持 `data-plugin-css` 幂等）：

```js
const css = [...cssSites, ...cssPlugins].join('')
```

注意：`css` 必须仍在 `page.js` 执行前可用；注入逻辑原样搬过去，不要改 `tagId`。

### 2.4 脚本与工程

`package.json`（版本升到 `0.7.0`）：

```json
"scripts": {
  "build": "node scripts/build.mjs",
  "data": "node scripts/embed-data.mjs && node scripts/build.mjs",
  "data:check": "node scripts/embed-data.mjs --check && node scripts/build.mjs --check",
  "preview": "node scripts/preview.mjs",
  "test": "node test/smoke.mjs",
  "prepublishOnly": "npm run data:check && npm test"
}
```

- `scripts/embed-data.mjs`：改写目标从 `lib/client.js` 改为 `src/data.js`，输出 `const LINKS/DETAILS/PLUGINS/I18N = ...`，`--check` 语义不变。
- `scripts/build.mjs`：`--check` 时对比内存产物与磁盘 `lib/client.js`，不一致则 `exit 1` 并提示跑 `npm run build`。
- `files` 字段保持只发 `lib/`（`src/` 不进 npm 包）。
- **不允许新增任何 dependencies / devDependencies**。esbuild 方案放弃：它的 external 处理与 `factory(require)` 契约冲突，且会破坏「零第三方依赖」的信任声明。此偏离需在交付说明里写明。

## 3. P0（五条，必须全部落地）

### P0-1 toast 生命周期

- `notice` 改为对象：`{ id, text, undo }`，`undo` 为可选「回到上一个 store」的函数。
- `notify(text, undo?)`：`setNotice({ id: Date.now(), text, undo })`。
- `useEffect` 依赖 `notice.id`：3200ms 后 `setNotice(null)`，清理定时器。
- 渲染：`<div className="redaiToast" role="status" aria-live="polite">`，内容 `text` +（有 undo 时）`<button className="redaiToastAction">撤销</button>` + `<button className="redaiToastClose" aria-label="关闭">×</button>`。
- CSS：`position:sticky; bottom:16px; margin:0 auto 16px; width:max-content; max-width:calc(100% - 48px)`，底下不再挤压内容（现在的 `redaiNavNotice` 删除）。
- 移除 `.redaiNavNotice` 类；新类 `.redaiToast / .redaiToastAction / .redaiToastClose`。
- 动效：入场 `translateY(6px)+opacity 0→1` 180ms `cubic-bezier(.16,1,.3,1)`；退场 140ms。

### P0-2 修饰键放行

`SiteCard` 的 `onClick` 首行：

```js
if (event.metaKey || event.ctrlKey || event.shiftKey || event.altKey) return
event.preventDefault()
onActivate(link)
```

`ⓘ` 按钮与 `☆` 按钮的 `stopPropagation` 保持不变。

### P0-3 确认态超时 + 点击外部关闭

- `useEffect(..., [armed])`：`armed === true` 时 4s 后 `setArmed(false)`。
- 菜单关闭：`useEffect(..., [mode])`，`mode === 'menu'` 时在 `document` 上挂 `pointerdown`，命中 `event.target.closest('.redaiNavActions')` 之外的区域则 `setMode(null); setArmed(false)`；卸载时移除。
- 确认态视觉：`redaiNavMenuItem.danger[data-armed="true"]` 加 `background: color-mix(in srgb, var(--dsw-alias-state-warn-label,#d33) 10%, transparent)` + `box-shadow: inset 0 0 0 .5px ...`。
- 依赖 `document` 时要做环境守卫（测试环境没有 `document.addEventListener`）。

### P0-4 页面级键盘层

把 `onKeyDown` 从 `<input>` 提到**页面根节点**：列表视图挂在 `.redaiNavPage`，详情视图挂在详情外层容器（见 P1-2）。统一函数 `handleKey(event)`：

| 键 | 条件 | 行为 |
|---|---|---|
| `Escape` | `view` 存在 | `setView(null)`；`preventDefault` |
| `Escape` | 菜单开 / 添加表单开 / armed | 依次关闭，`preventDefault` |
| `Escape` | 有 query | `setQuery('')`，`setActive(-1)` |
| `ArrowDown` / `ArrowUp` | `tab === 'sites'` 且不在添加表单的输入框内 | 移动 `active`，`preventDefault` |
| `Enter` | `active >= 0` 且事件源不是 input | 打开选中卡片 |
| `/` | 焦点不在输入框 | 聚焦搜索框 |

守卫：`event.target` 是 `input`/`textarea` 且键不是 `Escape` 时，除 `ArrowUp/Down`（搜索框内继续移动光标）外一律不拦截。

### P0-5 选中项滚入视口

- 页面根节点加 `ref={pageRef}`。
- `useEffect(..., [active])`：`if (active < 0 || !pageRef.current) return`，查询 `pageRef.current.querySelector('[data-active="true"]')`，存在则 `scrollIntoView({ block: 'nearest' })`。
- `SiteCard` 在 `active` 时输出 `data-active="true"`。

## 4. P1（七条）

### P1-1 点击语义：卡片=打开，ⓘ=详情

- `activate(link)` 改为**永远** `visit(link.url)`。
- 新增 `openDetail(link)`：`setView({ kind: 'site', url: link.url })`。
- `SiteCard` 新增可选 `onDetail`；仅当 `DETAILS[link.url]` 存在时由 `NavPage` 传入。
- 渲染顺序：`tile → meta → ⓘ → ☆ → ×`；`ⓘ` 类名 `redaiNavInfo`，`aria-label` 用字典 `action.detail`，默认 `opacity:0`，`card:hover` / `:focus-visible` / `.redaiNavCardActive` 时 `opacity:1`；触控目标用 `::after{inset:-4px}` 补到 30px。

### P1-2 详情页统一页壳 + 滚动恢复 + 粘性返回

- `NavPage` 在返回 `PluginDetail` / `SiteDetail` 时**外包一层**：

```jsx
<div className="redaiNavPage" ref={pageRef} onKeyDown={handleKey}>
  <div className="redaiDetailShell">{detailNode}</div>
</div>
```

`SiteDetail` / `PluginDetail` 组件自身的根节点仍必须是 `.redaiDetail`（smoke 测试按此断言），只改 `NavPage` 的外层。
- `.redaiDetailShell{padding:0 24px 40px;max-width:760px}`；`.redaiDetail` 去掉 `padding` 与 `max-width`，只留 `padding-top:8px`。
- 返回按钮粘性：`.redaiDetail > .redaiGhost{position:sticky;top:0;z-index:2;background:var(--dsw-alias-bg-base);margin-left:-2px}`，并在其外包一层 `.redaiDetailTopBar{padding:8px 0}`？——**不要新增包裹层**（会破坏测试的 9 块结构）；只给 ghost 加 sticky 与背景，靠 `top:0` 贴住滚动容器顶部。
- 滚动位置：`scrollPosRef`。进详情前 `scrollPosRef.current = pageRef.current.scrollTop`；`useEffect(..., [view])` 中当 `view === null` 时恢复 `pageRef.current.scrollTop = scrollPosRef.current`（用 `requestAnimationFrame` 包一层）。

### P1-3 计数口径

- 新增字典键：`count`（`{n} 个站点`）、`countFiltered`（`{n} / {total} 个站点`）、`countGroup`（`{n} / {total}`）。
- 顶部计数：`needle ? fill(t('countFiltered'),{n:total,total:baseTotal}) : fill(t('count'),{n:total})`，其中 `baseTotal` = 未过滤时去重后的站点数（`useMemo` 计算一次，不随 query 变）。
- 组标题计数：搜索态显示 `n / m`（m 为该组原始条数，自定义组/收藏组不受影响，无 needle 时只显示 `n`）。
- `banner.desc` 改为 `{n} 个常用站点分 {g} 组，收藏、搜索、键盘直达。零联网，数据只存在你自己的机器上。`，渲染时 `fill(t('banner.desc'), { n: 内置站点数, g: LINKS.groups.length })`。中英都要改。
- 插件 tab 的 `plugin.count` 保持原样（测试按字符串断言）。

### P1-4 空态给行动

站点列表空态（`visible.length === 0`）：

```jsx
<div className="redaiNavEmpty">
  <div className="redaiNavEmptyTitle">{t('empty')}</div>
  <div className="redaiNavEmptyHint">{fill(t('empty.hint'), { q: query })}</div>
  <div className="redaiNavEmptyActions">
    <button className="redaiGhost" onClick={() => { setDraft({title: query.trim(), url:'', desc:''}); setMode('add'); setFormError('') }}>{fill(t('empty.add'), { q: query })}</button>
    <button className="redaiGhost" onClick={() => setTab('plugins')}>{fill(t('empty.plugins'), { q: query })}</button>
  </div>

```

- 只有 `query.trim()` 非空时才渲染两个按钮。
- 新增字典：`empty.hint` / `empty.add` / `empty.plugins`。
- 空态整体垂直居中：`.redaiNavEmpty{display:flex;flex-direction:column;align-items:center;justify-content:center;gap:10px;min-height:320px;padding:48px 0}`。
- **注意**：`byClass(node,'redaiNavEmpty')` 仍必须唯一，插件空态保持单个 `redaiNavEmpty` 节点。

### P1-5 删除 / 清空可撤销

- `remove(link)`：`const prev = store; update(removeLink(store, link.url)); notify(fill(t('notice.removed'),{title:link.title}), () => update(prev))`。
- `clearAll()` 第二段：同样带 `undo: () => update(prev)`。
- 新增字典：`notice.removed`、`notice.undo`、`notice.close`。
- 撤销执行后 `setNotice(null)`。

### P1-6 插件榜筛选 + 复制命令

- 筛选条（仅 `tab === 'plugins'`，位于 `redaiPluginNote` 之后）：

- Chip 文案：`plugin.filter.all`（`全部 {n}`）、`plugin.host.none` / `plugin.host.unknown` / `plugin.host.yes`（复用已有键），数量用 `fill` 追加在括号里：`零宿主端 (1)`，键名 `plugin.filter.count`。
- 状态 `filter` 默认 `'all'`；与搜索 query 是**与**关系。
- 计数 `redaiNavCount` 在插件 tab 反映筛选后条数（沿用 `plugin.count`）。
- 复制：插件详情里把安装命令改为

```jsx
<div className="redaiInstallRow">
```

`redaiInstall` 的 children 必须仍是**纯字符串**（测试按字符串断言）。`copyInstall` 用 `navigator.clipboard.writeText(install)`，失败回退 `document.execCommand('copy')` 用临时 textarea；成功后 `setCopied(true)`，1600ms 复位。`copied` 用组件内 `useState` —— 但 `PluginDetail` 目前是纯函数组件且测试直接调用它！**不要**在里面加 hooks。改为：复制状态由 `NavPage` 管（`copyState`），通过 `props.copied` / `props.onCopy` 传入；测试调用时不传则不渲染「已复制」态，按钮仍渲染（文案取 `plugin.copy`）。

## 5. 动效（四个，全部可降级）

统一要求：所有时长从 CSS 变量取；末尾追加全局降级块：

```css
@media (prefers-reduced-motion: reduce){
  .redaiNavPage *, .redaiNavPage *::before, .redaiNavPage *::after{
    animation-duration:1ms!important;animation-iteration-count:1!important;transition-duration:1ms!important;
  }
}
```

`:root` 不新增全局变量（避免污染宿主），统一在 `.redaiNavPage` 上定义局部变量：

```css
.redaiNavPage{--redai-fast:120ms;--redai-state:240ms;--redai-slow:380ms;--redai-ease:cubic-bezier(.16,1,.3,1)}
```

### 动效 1 · 星尘收藏

- 已收藏时点击 → 变未收藏：只做 `transform:scale(.9)` 140ms，不喷尘。
- 未收藏 → 收藏：字形 `scale .86→1.14→1` 240ms；同时插入 `span.redaiDust` 内含 4 个 `<i>`，`--dx/--dy` 分别为 `7px,-7px` / `8px,2px` / `2px,9px` / `-5px,7px`，380ms `opacity .95→0`、`scale 1→.3`。
- 实现：`SiteCard` 内用 `React.useState` 记录 `dustKey`，点击时自增；`dustKey > 0` 时渲染 `.redaiDust`，`animationend` 后清空。**注意** `SiteCard` 可直接用 hooks（它是组件，测试用 `node.type(props)` 调用会走 `flatten` 的 `typeof node.type === 'function'` 分支——stub 的 `useState` 可用，返回 `[initial, noop]`，`useEffect` 是 noop，安全）。
- 颜色：`.redaiNavStar.on{color:light-dark(#d99a00,#f0b429)}`，`.redaiDust i{background:currentColor}`。

### 动效 2 · 键盘光标竖条

```css
.redaiNavCardActive{background:color-mix(in srgb, var(--dsw-alias-brand-primary) 8%, transparent)}
.redaiNavCardActive::before{
  content:"";position:absolute;left:0;top:7px;bottom:7px;width:2px;border-radius:2px;
  background:var(--dsw-alias-brand-primary);animation:redaiRail var(--redai-fast) var(--redai-ease) both;
}
@keyframes redaiRail{from{transform:scaleY(.2);opacity:0}to{transform:scaleY(1);opacity:1}}
```

卡片左内边距已是 11px，竖条落在 padding 内，不挤压内容。

### 动效 3 · 计数滚动

- 新组件 `Count({ n, total, t })`（放 `components.js`）：输出 `<span className="redaiNavCountNum" key={n}>`，数字列 `translateY(-100%)` 140ms 由旧值滚到新值。
- 简化实现：`key={String(n)}` 触发重挂载 + `@keyframes redaiOdo{from{transform:translateY(100%);opacity:.35}to{transform:none;opacity:1}}`，容器 `display:inline-block;overflow:hidden;height:18px`，内层 `display:block`。
- **不追求**双值对滚（成本高、易抖动）；单值从下往上顶入即可，视觉上等价。
- 数字用 `font-variant-numeric:tabular-nums`。

### 动效 4 · 域名浮出

- `SiteCard` 的描述行改为：

```jsx
<div className="redaiNavMetaLine">
  <span className="redaiNavDesc">{link.desc}</span>
  <span className="redaiNavHost">{host}</span>
</div>
```

`host = link.url.replace(/^https?:\/\//,'').replace(/\/$/,'')`。
- CSS：`.redaiNavMetaLine{position:relative;height:16px;overflow:hidden}`，两个 span 绝对定位 `inset:0`，`transition:opacity var(--redai-fast) ease, transform var(--redai-fast) ease`；hover / `.redaiNavCardActive` 时 desc 淡出上移 2px、host 淡入。
- `@media (hover:none)` 下禁用交叉淡入（host 不显示）。
- 无 `desc` 时只渲染 host 一个（不交叉）。
